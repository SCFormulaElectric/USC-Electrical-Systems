3. kicad-batch (built this session)  ->  C:\Git\USC-Electrical-Systems\tools\kicad-batch\
==========================================================================================
Files: server.py (MCP server, `uv run --script`, deps inline), pcb_worker.py (runs under KiCad's
bundled python.exe, does all board edits/queries), token_report.py (per-tool cost of a session
transcript), README.md (full tool docs). Needs a Claude Code restart / `/mcp` reconnect to load.

Tools
- batch(calls)        any mcp-server-kicad tool, many calls in one round trip (schematic edits too).
- pcb_apply(ops)      many board edits, one save. Ops: track, via, move, field, ref_text, edge_poly,
                      zone, merge_zones, zone_priority, delete_vias, delete_tracks, delete_shapes.
                      Nets by NAME (KiCad 10 renumbers nets). check=True -> applies to a scratch copy
                      beside the board and returns only the DRC violations the edit adds.
- pcb_query(kinds)    compact filtered tables: footprints, pads, tracks, vias, nets, zones, outline.
- drc_summary / erc_summary   counts + a few filtered lines; only_new=True diffs against the last run.
- render(bbox)        small PNG of a board region (use 400-900 px).
Typical layout loop: pcb_query -> plan geometry in a local Python script -> pcb_apply(check=True)
-> pcb_apply -> drc_summary(exclude silk types) -> render one region.

Safety built in
- Writes refused while kicad/pcbnew/eeschema runs (an open editor overwrites external edits on save);
  force=True only for files KiCad does not have open. The user often has KiCad open - check first.
- Saves only if every op succeeds; previous board kept as <board>.batch-bak.
- After ops it refills zones, rebuilds connectivity and REFUSES the save if any new track/via changed
  net: KiCad silently gives new copper the net of other-net copper it overlaps (hides shorts).
- Removed items are kept referenced until the worker exits (GRAVE) and the worker exits via os._exit:
  otherwise pcbnew's SWIG wrappers free removed C++ objects and segfault. Keep both if you edit it.

Quirks handled: kicad-cli 10.0.5 ERC positions are labelled mm but divided by 100 (rescaled);
DRC re-picks unconnected-item pairs every run (diffs compare per-net counts).

Ideas not done yet: "commit the last checked ops" so check + apply do not send the op list twice
(that is 33 of 38 KB of call data); schematic batch still loads/saves the file once per call inside.
